Generated by `pnpm memory`, on Node.js only (it needs `--expose-gc`). Each measurement runs in a new process, 3 times in a shuffled order: `node --expose-gc --max-semi-space-size=64 memory/worker.ts <library> <camel|snake> <scenario>`, which can be run alone to check it. The tables show the mean of the 3 runs, and each run.

- **Allocated**: heap allocated by one call, the median of 51 calls, with a garbage collection before each one and none during it.
- **Result**: the part of it that is the converted object. **Temporary**: the rest, garbage left by the call.
- **Kept**: heap still used after the calls, like a cache kept between calls.

Every run, with the samples of every call, is in [`memory.json`](./memory.json), and `node memory/report.ts` writes this file from it.
